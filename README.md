# Stockify screens

Clickable UI design for Stockify – Company Intelligence, US Private Equity & MLDs.

- Live: https://malharlakdawala.github.io/stockify-screens/
- File: `Stockify-ALL-with-analyst-review-(for-Malhar).html` (single self-contained page)

## Working together
1. `git pull` before you start.
2. Edit the HTML, open it in a browser to check.
3. `git add -A && git commit -m "what changed" && git push`

The live link updates about a minute after each push.
